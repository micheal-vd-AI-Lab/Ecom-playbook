# ECOM Playbook

A complete static e-commerce course website.

## Files
- index.html — page structure and course content
- style.css — responsive design
- script.js — course navigation, progress tracking, tools and calculators
- cover.jpg — uploaded cover image

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload all four files to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. Open the generated GitHub Pages URL.

Course progress is saved in the visitor's browser using localStorage.
